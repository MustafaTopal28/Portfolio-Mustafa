# 👋 Portfolio — Mustafa

Portfolio personnel présentant mon parcours, mes compétences et mes projets en développement web.

🔗 **Live demo :** [ton-url.vercel.app](https://ton-url.vercel.app)

## 🚀 Aperçu

Ce portfolio met en avant :
- Mon parcours et ma formation
- Mes compétences techniques (avec badges colorés par stack)
- Mes projets réalisés, avec pages détaillées
- Un formulaire de contact fonctionnel

## 🛠️ Stack technique

- **React** + **TypeScript**
- **Vite** — bundler
- **React Router** — routing
- **Tailwind CSS** — styling
- **Formspree** — gestion du formulaire de contact
- Déploiement sur **Vercel**
